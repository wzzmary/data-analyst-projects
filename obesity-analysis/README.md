# Obesity Analysis — Latin America

## Objective
Analyze obesity patterns among Latin American women using statistical methods.

## Dataset
- Source: Kaggle
- Sample: 1,043 women

## Methods
- Hypothesis testing
- Confidence intervals (95%)
- Central Limit Theorem

## Tools
- R
- Excel

## Key Result
The analysis showed a statistically significant result based on hypothesis testing.

- Statistical analysis
- Hypothesis testing
