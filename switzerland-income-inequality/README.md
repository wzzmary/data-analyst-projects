## Objective
Study income disparities in Switzerland based on region, education, age, and household type.

## Dataset
- Swiss income dataset

## Methods
- Data visualization
- Regression analysis
- Comparative analysis

## Tools
Python, pandas, matplotlib, Tableau

## Key Results
Highlighted strong disparities depending on region and socio-economic factors.

## Skills Demonstrated
Data analysis, visualization, storytelling
